# Кеши преобразований принадлежат текущему набору DLL

В modern-компиляторе четыре кеша `compiled_type_node` больше не являются
полями семантического узла. Это вычисляемые обращения к
`CompilerReflectionCaches.Current.ConversionCaches`.

`CompilerConversionCacheState` хранит для каждого узла-владельца отдельные
словари implicit-to, implicit-from, explicit-to и explicit-from. Владельцы
сравниваются по ссылке: разные семантические узлы одного CLR-типа не смешиваются.
Словари создаются лениво при первом обращении к преобразованиям данного узла.

Сам `SystemLibrary.integer_type` может жить весь процесс, но он больше не хранит
словарь с пользовательским enum или ссылку на старый объект состояния кешей.
Каждое обращение получает актуальное состояние.

## Срок жизни

- При обычной повторной компиляции неизменного набора DLL сохраняются тот же
  объект состояния, словари и найденные преобразования.
- При перезагрузке набора DLL или принудительном rebuild состояние преобразований
  заменяется целиком перед освобождением старого контекста.
- Полная замена `CompilerReflectionCacheState` также автоматически создаёт новое
  состояние преобразований. Обходить старые системные узлы не требуется.
- Отдельный вызов `RemoveAssembly` тоже инвалидирует непустое состояние
  преобразований целиком. В штатном цикле перезагрузки оно уже заменено, поэтому
  обработка каждой следующей DLL не выделяет ещё один объект кешей.

Сбрасываются все вычисленные преобразования текущего набора, включая чисто
системные записи в этих четырёх кешах. Это не удаляет реализации преобразований:
при следующем обращении алгоритм снова находит их и кеширует результат.
Остальные системные reflection-кеши продолжают жить по прежним правилам.

Убраны `initialTypeNodes`, снимок слабых ссылок на исходные системные узлы,
обход вложенных словарей и распознавание принадлежности ключей/значений сборке
специально для очистки преобразований. Здесь больше нет исключений для integer,
enum, Flags, конкретной сигнатуры или направления преобразования.

Алгоритмы поиска преобразований, enum/Flags, предыдущий этап с двумя таблицами
операторов и строгая `VerifyPreviousGenerationWasUnloaded` не изменены.
Перенос ограничен `PABCNET_MODERN`: legacy сохраняет прежние поля узлов.

## Тесты

`ReflectionCacheUnloadTest/SystemValueAudit.cs` включён в обычный запуск теста.
Проверяются:

- отсутствие полей-словарей преобразований в modern-узле (по типу поля,
  а не только по четырём заранее известным именам);
- реальное enum → integer и повторное использование найденного преобразования;
- независимость всех четырёх направлений и словарей разных владельцев;
- разные узлы одного CLR-типа после полного сброса;
- получение новых пустых словарей старым постоянным узлом после смены состояния;
- отдельное удаление сборки, штатная граница набора DLL и полная замена состояния;
- сборка старого объекта кешей и настоящая выгрузка DLL через два независимых
  `WeakReference`, после выхода из `NoInlining`-метода.

Старая реализация с полями внутри узла ожидаемо не проходит проверку владения
кешами. Это отрицательный контроль архитектуры, а не утверждение, что предыдущие
исправления выгрузки перестали работать.

В тестовой C#-DLL добавлены implicit-преобразования из/в integer и explicit-
преобразования из/в string; второй класс преобразуется в integer с другим
результатом. `CompilerAssemblyReloadTest` компилирует и запускает Pascal-программу
с ними, всеми шестью сравнениями enum и Flags, повторяет её без изменения DLL,
проверяет отсутствие лишних загрузок, затем выполняет четыре rebuild в том же
процессе. Режим `--stress` дополнительно делает 50 замен DLL.

Обычные команды после сборки тестовых проектов и modern-комплекта:

```powershell
dotnet tests/ReflectionCacheUnloadTest/bin/Debug/net10.0/ReflectionCacheUnloadTest.dll
dotnet tests/CompilerAssemblyReloadTest/bin/Debug/net10.0/CompilerAssemblyReloadTest.dll D:\PABC_GIT\bin-net10\pabcnetc.dll --stress
```

## Результаты проверки второго этапа

- Modern-комплект и legacy `TreeConverter` для net472 собраны успешно.
- Прямые проверки владения кешами и выгрузки контекста прошли; старая реализация
  с полями узла ожидаемо отклонена отрицательным контролем архитектуры.
- Реальные implicit/explicit-преобразования, enum/Flags, повторная компиляция
  неизменных DLL и четыре принудительные перезагрузки прошли.
- Нагрузка: 50 замен DLL с выгрузкой старых контекстов; private memory
  в этом прогоне — 129 → 127 МБ.
- IntelliSense: локальные пакеты и пять повторных восстановлений ML.NET/MKL
  в одном сервере, без его перезапуска, прошли.
- Полный прогон: **1913 прошли, 0 ошибок, 44 пропущены** (41 modern-исключение),
  время — 6 минут 11 секунд. Правила пропуска не менялись.

Проверки выполнены на отдельном комплекте
`.codex-build/conversion-state/bin-net10`; файлы запущенной IDE не заменялись.
Строгая проверка выгрузки оставлена включённой.
