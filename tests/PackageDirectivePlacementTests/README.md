# Размещение директивы package: первый этап

В .NET 10 директива `{$package}` должна находиться в начальном блоке комментариев
и директив, до `unit`, `program`, `uses`, объявлений и маркера короткой программы.
Комментарии, обычные директивы и выключенные условной компиляцией ветви не
считаются кодом. Для поздней директивы сообщаются файл и строка ошибки.
Используется существующий лексер с обработкой строк, комментариев и include.
Поведение .NET Framework не изменено. Предварительный обход модулей не добавлен.

```powershell
dotnet run --project tests/PackageDirectivePlacementTests -f net10.0 -c Release -p:PABCNET_LEGACY_ONLY=false
dotnet run --project tests/PackageDirectivePlacementTests -f net472 -c Release -p:PABCNET_LEGACY_ONLY=true
```

46 проверок на каждой платформе охватывают оба вида перевода строки, допустимое
и ошибочное размещение, комментарии, строки и интерполяцию, условную компиляцию,
include и короткие программы. Восстановление пакетов и сеть не требуются.
В интеграционных NuGet-тестах директивы перенесены в начало временных копий
старых примеров; оригиналы для .NET Framework не изменены.

Восстановление пакетов по ходу подключения модулей, чтение их требований из PCU
и общий контроль конфликтов с `{$reference}` проверяются отдельно:
[NuGetRestoreTests](../NuGetRestoreTests/README.md), режим `--module-packages`.
