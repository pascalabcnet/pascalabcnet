# Проверки общего редактора

Набор запускается под Windows и проверяет прежний шрифт по умолчанию, Unicode-текст, вставку, undo/redo, вычисление столбца (в том числе после очистки документа и при отключённом контроле), сохранение и загрузку.

Сборка с конкретной DLL:

```powershell
dotnet build tests/SharedEditorTests/SharedEditorTests.csproj -c Release -p:EditorAssemblyPath=D:\full\path\ICSharpCode.TextEditor.dll --output .codex-build/shared-editor-tests
& .codex-build/shared-editor-tests/SharedEditorTests.exe
```

Для сравнения запускать в отдельных каталогах с исходной Windows-DLL и кандидатом. Системный буфер обмена эти проверки не изменяют. Работа Mono/Linux и визуальная отрисовка требуют отдельной проверки на ALT.

Четыре случая подсказок проверяют короткую сигнатуру, описание, несколько строк и счётчик перегрузок. Строки `TIP` содержат размеры и SHA256 PNG, нарисованных в памяти: при сравнении исходной Windows-DLL и кандидата на одной машине они должны совпасть. Проверки не открывают всплывающие окна и не меняют фокус рабочего приложения.

FontContainer проверяется с Courier New, Consolas и Arial при размерах 10, 11, 14 и 20 pt, включая повторное присваивание DefaultFont. Проверяются четыре начертания; строки FONT и FONTIMAGE позволяют сравнить размеры/высоту шрифтов и изображения текста с исходной DLL на той же машине. Смена системного DPI этими тестами не выполняется.

DeclarationViewWindow проверяется в отдельной тестовой форме: вызов GotFocus должен сохранить фокус в другом поле, не переводя его в связанный редактор на Windows. Также проверяются передача события и параметры пассивного окна. Само всплывающее окно не показывается. Для совместимости с исходной Windows-DLL дополнительное Linux-свойство задаётся через reflection только при его наличии.

AbstractCompletionWindow проверяется настоящим показом небольшого тестового окна: восстановление фокуса редактора при открытии, необработанная клавиша, закрытие по Escape, однократный Closed/Dispose и закрытие при переходе в другое поле без возврата фокуса. Тестовые формы закрываются после проверок.

Режим `--scale -1` проверяет реальное определение текущего Windows DPI; `--scale 1`, `--scale 1.5`, `--scale 2` проверяют заранее заданный кэш масштаба, ширину и изображение поля значков. Каждый режим запускается отдельным процессом из-за статической ширины в Windows-редакторе. Сравнивать строки SCALE с исходной DLL; PNG включает также DPI метаданные. Это не замена ручной проверке при реальном переключении системного масштаба. Для сохранения изображения поля рядом с тестовым EXE можно задать `PABC_EDITOR_TEST_IMAGES=1`.

TextArea проверяется с несколькими обработчиками клавиши: первый принявший символ должен остановить вызов остальных в Windows. Также проверяются необработанная клавиша, отсутствие подписчиков и отсутствие Mono-таймера в Windows-редакторе. Проверки Mono-веток на Windows запускаются отдельно через LinuxCompletionFocusTests с `PABC_TEST_MONO_EDITOR_BRANCH=1`; переключатель есть только в тестовом коде, не в редакторе.

После перехода на одну DLL проверка подготовленного дистрибутива:

```powershell
./tests/SharedEditorTests/Test-SharedEditorDistribution.ps1
```

Проверяет идентичность и одинаковое содержимое редактора в Libraries, bin и Linux-дистрибутиве, отсутствие обязательной WPF-зависимости и старого имени редактора у Linux-потребителей. Обе оболочки используют проект ICSharpCode.TextEditor; платформенные различия выбираются во время выполнения.
