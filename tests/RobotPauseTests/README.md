# Пауза и шаг Робота

Запуск в Windows из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/RobotPauseTests/Test-RobotPause.ps1
```

Тест извлекает **сам класс синхронизации из производственного RobotField.pas**,
компилирует и запускает его в .NET 10: начальная пауза, проверки датчиков,
50 одиночных шагов, раннее нажатие, продолжение, повторная пауза и
невозможность продолжить после ошибки. Рабочие потоки теста фоновые.
Robot и RobotField отдельно компилируются из изменённых исходников для
Framework и .NET 10 в изолированных копиях, без изменения рабочих PCU.

С ключом `-Gui` дополнительно запускается настоящее окно Робота .NET 10:
автоматически нажимаются Пуск/Стоп/Шаг и проверяется счётчик команд,
повторный шаг после паузы, продолжение и столкновение со стеной.
Нужен интерактивный рабочий стол Windows; процесс ограничен 45 секундами.
Отдельный запуск проверяет закрытие окна на паузе: сохранён штатный Halt
GraphABC с принудительным завершением процесса (код 1 или -1).

Ручная проверка: открыть robot_smoke.pas в режиме .NET 10. До «Пуск» Робот
не движется; каждое нажатие «Шаг» выполняет ровно одну команду (вправо,
влево, закрасить). «Пуск» продолжает выполнение. Проверить «Стоп» на длинном
цикле движений и закрытие окна во время паузы. Отдельно проверить столкновение
со стеной: показывается ошибка Робота, кнопки выполнения отключаются, программа
не продолжает движение. Повторить обычный пример в Framework/Mono.

Только ветка PABCNET_MODERN использует кооперативную паузу. Стоп действует
в контрольных точках Робота; произвольный цикл без его вызовов не прерывается.
