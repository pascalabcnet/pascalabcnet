# Linux LanguageServer document synchronization: completion, parameter help and document synchronization

This fixture links the shared transport and document synchronizer with the Linux session wrapper. It verifies mode gating, unsaved active/inactive sources, edits, Save As (including Cyrillic URI), close versus cancellation, case-sensitive URI bookkeeping, connection recovery, reuse and disposal. A real LanguageServer test checks completion responses internally to prove that changed unsaved types reach the server; it includes an unfinished dot expression after a changed local type. The UI fixture uses the real Linux adapter with the shared completion trigger: Enter/Tab, prefix replacement, Escape, obsolete-response rejection and editor focus. Parameter tests cover the real Linux popup with both a fake transport and the actual LanguageServer, active parameter highlighting, nested calls, settings and obsolete responses. Legacy analysis is suspended/resumed without changing preferences; no duplicate old popup is allowed.

Build with `IdeReferenceDirectory` and `OutDir` pointing to an isolated Linux distribution containing the common PluginsSupport.dll and editor. Use the Linux IDE exe.config as LinuxLanguageSessionTests.exe.config on Windows. Run `LinuxLanguageSessionTests.exe <net10-kit>` or `mono LinuxLanguageSessionTests.exe <net10-kit>`. Without the kit argument only fixture checks run. Tests use temporary source paths and preserve user settings. Windows execution does not replace ALT UI verification.

Manual ALT check: in .NET 10 mode, the separate status item reads `LSP: N файлов`. Open a second Pascal source tab, edit without saving, Save As, cancel closing a changed tab, then close it. Tab count must stay stable through Save As/cancellation and decrease only on actual close. Check modern string dot completion and prefix insertion with Enter/Tab/Escape. Check parameter hints on `(`, `[` and comma, nested calls, overload switching and Escape without focus loss. Disabling parameter hints must prevent requests. Hover now uses the external provider; Ctrl-click now uses the shared modern navigation provider. Check hover appearance/hiding and focus manually in ALT. Backend checks cover unsaved Cyrillic identifiers and invalidation after edits. Switch to Mono and back: the counter hides/restores and ordinary compilation stays usable. Exit the IDE and check that its LanguageServer process exits too.

Navigation checks cover plain versus Ctrl-click, one-based IDE coordinates, focus preservation, mode detachment, and real server navigation to unsaved units and .NET metadata without disk writes. Verify tab activation/read-only metadata manually in ALT.
