# Пауза и шаг Чертёжника в .NET 10

Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/DrawmanPauseTests/Test-DrawmanPause.ps1 -Gui
```

Тесты компилируют текущие Drawman и DrawManField из исходников для Framework
и .NET 10 в изолированных копиях компилятора, без изменения рабочих PCU.
Класс синхронизации извлекается непосредственно из DrawManField.pas и проверяется
на начальную паузу, 50 одиночных разрешений, раннее нажатие, Пуск/Стоп и
невозможность продолжения после ошибки.

Ключ `-Gui` запускает настоящее окно Чертёжника и нажимает его кнопки:
начальная пауза, отдельный шаг для каждой из четырёх команд PenDown, ToPoint,
OnVector, PenUp, Пуск, Стоп, шаг после Стоп, продолжение, выход за границы поля
и закрытие окна на паузе. Каждый процесс ограничен 45 секундами. Без `-Gui`
выполняются проверки синхронизации и компиляции без запуска графического окна.

Ветка Framework/Mono сохраняет прежний Suspend/Resume. Новая ветка включена
только при PABCNET_MODERN. Один OnVector потребляет одно разрешение в ToPoint,
а не два. Кооперативная пауза действует на границах команд Чертёжника, но не
останавливает произвольный цикл пользовательского кода без его вызовов.

Ручной пример — drawman_smoke.pas. До Пуска/Шага он должен ждать; каждое нажатие
Шаг выполняет одну команду. При закрытии сохранён штатный Halt GraphABC,
принудительно завершающий процесс (код 1 или -1).
